# attic

The 2D half of the film, retired when teti asked for the five languages to happen
**on the flower, in the room**, rather than in a cut to 2D. Everything here still
runs — `render.py` drives `video.html` exactly as it did — but nothing in
`build.sh` calls it any more.

Kept rather than deleted because the technique renderers in `video.html` (the
bristled wipes, the ink line generated from the flower's own geometry, the paint
engine) are the reference the Blender looks were translated from, and because
`git log` on a deleted file is a worse archive than a directory.
