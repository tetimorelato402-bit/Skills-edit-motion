# Typefaces

Self-hosted, for 003's reason: this container has come back from restarts with an empty
`/usr/local/share/fonts`, and a silent DejaVu fallback would not be caught until the film
was assembled. `fc-list` is a check somebody has to remember to run. An `@font-face` is not.

All of these are under the **SIL Open Font License 1.1**, which permits redistribution
inside a work like this one.

| file | family | used for |
|---|---|---|
| `Archivo.ttf` | Archivo (variable: `wght` 100–900, `wdth` 62–125) | SIT STILL. / KEEP UP., pages 1 and 5, the payoff. The width axis is what narrows the type as the film runs out of room. |
| `BigShoulders.ttf` | Big Shoulders Display (variable: `wght` 100–900) | page 4 — condensed and urgent |
| `BebasNeue.ttf` | Bebas Neue | the 3 · 2 · 1 countdown |
| `InstrumentSerif.ttf` | Instrument Serif | the app's own register: card headlines, and the end mark |
| `Redacted.ttf` | Redacted | the last page, once the words stop being words |
| `inter.woff2` | Inter (variable) | UI card sub-labels |
| `plexmono.woff2` | IBM Plex Mono | the readout, eyebrows, the GPS stamp |

`playfair.woff2` was v3's serif; Instrument Serif replaced it and it has been removed.
