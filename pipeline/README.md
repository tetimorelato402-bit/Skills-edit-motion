# Stone Memory pipeline

Frame-accurate tooling for the faceless symbolic motion pieces described in `../CLAUDE.md`. One still from OpenArt in, one mp4 out, with the reveal locked to a chosen timestamp in the song.

```
bash pipeline/install.sh      # ffmpeg + numpy + pillow
bash pipeline/test.sh         # synthetic end-to-end run, proves the sync
```

## The four tools

| Tool | Step | What it does |
| --- | --- | --- |
| `cue.py` | 2, song selection | Lists candidate cues (drops, energy jumps, ends of silence) with timestamps and frame numbers. `--snap` rounds a chosen time to the frame grid. |
| `render.py` | 4, 5, 6 | Motion pass (slow push, drift, parallax) + VFX layer (light on the hidden shape, crack, chromatic split, grain, tremor) + assembly with the song. Pipes raw frames straight into ffmpeg. Writes a `.sync.json` sidecar. |
| `verify.py` | 6 | Reads the finished mp4 back, finds the first frame where the hidden shape lights up and where the audio jumps, compares both to the cue frame. Exit code 1 means it does not ship. |
| `synth.py` | testing | Procedural banded-stone still, mask of a buried doorway, and a test track with a drop at a known time. |

## How the timing works

- The preset gives `duration` (piece length) and `reveal_at` (seconds into the piece where the cue lands).
- `--cue` is the timestamp in the song. The renderer starts the song at `cue - reveal_at`, so the song's moment lands exactly on piece time `reveal_at`.
- `reveal_at` is snapped to the frame grid: cue frame = `round(reveal_at * fps)`. Audio is trimmed with sample accuracy by ffmpeg, video frames are generated by index, so both sides agree by construction.
- Every VFX curve is defined in seconds relative to the cue frame. Move the reveal and nothing else needs re-timing.
- The light on the hidden shape has a hard step on the cue frame (`light.hit`), so the reveal is visible, and measurable, on that exact frame, then eases to full.

## Presets

`presets/default.json` holds the reusable values with a `_doc` line for each group. A piece preset lives next to the piece (`pieces/<piece>/preset.json`) and only lists what it overrides. A preset can name `"base": "reveal-silence"` to build on a variant instead of the default.

Adjust presets, not code. If a piece needs a new effect, add it to `render.py` with a preset section and a default, so the next piece gets it too.

## Inputs a piece needs

1. `base.png`: the locked OpenArt still, composed with the hidden detail from the start.
2. `mask.png`: where the hidden shape is (white on black, or alpha). Paint it over the still, or pass `--region cx,cy,rx,ry` (an ellipse in 0..1 coordinates) for a quick preview.
3. The song file and the cue timestamp from `cue.py`.

## Typical run

```
python3 pipeline/cue.py song.wav --fps 30
python3 pipeline/cue.py song.wav --fps 30 --snap 47.31
python3 pipeline/render.py --image pieces/01-what-the-stone-remembers/base.png \
    --mask pieces/01-what-the-stone-remembers/mask.png \
    --audio song.wav --cue 47.3 \
    --preset pieces/01-what-the-stone-remembers/preset.json \
    --out pieces/01-what-the-stone-remembers/out/final.mp4
python3 pipeline/verify.py pieces/01-what-the-stone-remembers/out/final.mp4
```

For a quick motion preview without the song, drop `--audio` and pass `--cue` equal to `reveal_at`.
